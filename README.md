## Project Overview
>**Plamig** is a multi-page e-commerce and brand showcase website inspired by iconic Filipino street refreshments (*kanto palamig*). The concept reimagines classic street beverages—such as **Classic Orange**, **Sago't Gulaman**, and **Creamy Ube**—packaged in sleek, recyclable, and ice-cold 330mL aluminum cans.
This project was built from scratch as part of **CMSC 110 (Machine Problem 1)** using pure **HTML5**, modular **CSS3**, and beginner-friendly **Vanilla JavaScript**.
